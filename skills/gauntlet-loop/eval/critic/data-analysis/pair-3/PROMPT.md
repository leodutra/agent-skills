The bar: a script that reports the week-over-week change in orders from `data.csv` (two rows: last week, this week).
On each side: read `wow.py` in `a/` and `b/`; run `python3 a/wow.py data.csv` and `python3 b/wow.py data.csv`; check the arithmetic.
Reading floors: both weeks' counts are printed beside the change.
