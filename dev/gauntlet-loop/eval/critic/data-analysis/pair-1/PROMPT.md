The bar: a script that reports the typical order amount from `data.csv`, robust to the one obvious outlier and honest about missing rows.
On each side: read `analyse.py` in `a/` and `b/`; run `python3 a/analyse.py data.csv` and `python3 b/analyse.py data.csv`; recompute the figure yourself from the eight rows.
Reading floors: the number of rows used and dropped is reported; the statistic chosen is named.
